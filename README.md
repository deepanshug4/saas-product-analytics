# 📈 SaaS Growth Analytics Dashboard

An end-to-end Product Analytics project that simulates a SaaS business, generates realistic customer activity, and provides interactive insights into user growth, acquisition, retention, and recurring revenue.

The project demonstrates the complete analytics workflow—from synthetic data generation to KPI reporting and dashboard visualization—using Python and Streamlit.

---

## 🚀 Project Overview

This project was built to replicate the type of analytics performed by Product Analytics and Data Science teams at SaaS companies.

It includes:

- Synthetic SaaS data generation
- Business KPI calculation
- Customer acquisition analysis
- Product engagement analysis
- Monthly cohort retention analysis
- Revenue analytics
- Interactive Streamlit dashboard

## 📈 Business Metrics

The dashboard tracks several common SaaS KPIs.

| Metric | Description |
|---------|-------------|
| Total Users | Number of registered users |
| Paid Users | Customers with active or historical subscriptions |
| Activation Rate | Users completing key onboarding actions |
| Paid Conversion Rate | Percentage of users who become paying customers |
| Monthly Recurring Revenue (MRR) | Revenue from active subscriptions |
| Average Revenue Per Paying User (ARPU) | Average revenue generated by paying customers |
| Churn Rate | Percentage of cancelled subscriptions |

## ▶️ Running the Project

### 1. Clone the repository

```bash
git clone https://github.com/<your-username>/saas-growth-analytics.git
cd saas-growth-analytics
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Generate the synthetic dataset

```bash
python src/generate_data.py
```

### 4. Run exploratory analysis

```bash
python src/analysis.py
```

### 5. Launch the dashboard

```bash
streamlit run dashboard/app.py
```

## 📌 Example Business Insights

Using the generated dataset, the dashboard can identify insights such as:

- Referral users have the highest paid conversion rate.
- Enterprise customers contribute the largest share of recurring revenue.
- Higher product engagement is associated with stronger customer retention.
- Paid Ads drive volume but convert less efficiently than Referral and Organic Search.
